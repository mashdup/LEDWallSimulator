LED wall content canvas

Point the wall app at this page: source Live web page, URL http://127.0.0.1:8080/content.html?wall=1, capture 400 × 400, auto-zoom off, zoom 20, speed 0. The wall then mirrors the canvas one cell per 20 px block, refreshed at the page's poll rate. The ?wall=1 parameter hides this panel so the page is exactly 400 × 400 — without it, a full-page capture drags this text into frame.

Script API on window.WALL: set(x,y,css), rect(x,y,w,h,css), clear(), grid (20), cell (20 px), canvas, ctx. Drive it from createClock(33).start() (a worker clock — hidden tabs freeze requestAnimationFrame) and the wall follows.
